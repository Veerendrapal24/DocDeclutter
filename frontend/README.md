# DocDeclutter Frontend

This folder will contain the React + Vite + Tailwind CSS frontend for the **DocDeclutter – Metro Document Automation** project.

The frontend will be responsible for:
- User authentication and session management
- Uploading documents for processing
- Displaying extracted information, classifications, and summaries
- Interacting with the backend APIs

## Tech Stack
- **React** (with functional components and hooks)
- **Vite** – fast development server & bundler
- **Tailwind CSS** – utility‑first styling

## Development
1. Install Node.js (>=18) and npm.
2. Run `npm install` to install dependencies (see next section).
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

> **Note:** Do not commit any `.env` files. Use the `.env.example` at the project root for reference.
